Observational Assessment & Progress Tracking

Observing Computational Thinking during work cycles—mapping shelf behaviors, self-correction, and peer leadership to Transparent Classroom's 4-Stage framework.

Transparent Classroom Stages:

Introduced (I): Initial lesson presentation given by guide.

Practiced (P): Self-directed shelf work & repetitions.

Mastered (M): Independent execution, self-corrects, or teaches peer.

Needs More (NM): Requires re-presentation, scaffolding, or guide intervention.

Computational Thinking Observational Metrics

Look for these concrete indicators during shelf work and group activities to assess individual progress across the four CT competencies:

1

Decomposition

Task Breakdown

Child isolates sub-tasks when faced with multi-step processes or large grid routes.

Practiced: Segments a 10-step Kidbot grid path into three distinct 3-step sequences on the work mat.

Mastered: Verbally articulates sub-problems or plans function modules prior to placing command cards.

Needs More: Becomes overwhelmed by long paths; needs guide to cover portion of grid or reduce initial steps.

2

Pattern Recognition & Abstraction

Efficiency & Rules

Child identifies repeating sequences and bridges rules across different Montessori materials.

Practiced: Replaces consecutive directional cards with a "Loop 3x" card to condense code length.

Mastered: Spontaneously links Base-10 Stamp Game mechanics to Base-2 Binary Card place-value rules.

Needs More: Lays duplicate cards repeatedly without noticing loop opportunities; requires prompt to find repetitions.

3

Algorithmic Execution

Order & Logic

Child constructs linear, unambiguous instruction sequences to achieve a predictable result.

Practiced: Navigates a sorting network or Kidbot path accurately following card instructions without skipping steps.

Mastered: Compares multiple valid paths and selects the shortest or most efficient solution independently.

Needs More: Skips cards or executes steps out of order; benefits from using a pointer/token to track line-by-line progress.

4

Debugging & Control of Error

Self-Correction

Child utilizes built-in material controls of error to systematically isolate and correct flaws.

Practiced: Pauses execution upon error, steps back to the last valid step, and tests cards individually.

Mastered: Resolves logic errors without guide intervention; calmly assists peers in isolating "bugs".

Needs More: Clears entire card sequence when one error occurs; needs guidance on isolating single step errors.

Plane-by-Plane Observational Continuums

Reference these indicators when updating student progress status in Transparent Classroom:

Primary Level (Ages 3–6) Focus: Concrete Spatial Movement & Positional Logic

Introduced (I)

Attends guide presentation of Kidbot grid. Follows single-step physical directions (Forward, Left, Right) using body movement.

Practiced (P)

Lays 3–5 directional arrow cards in sequence to direct a peer "bot" to a target material on the rug.

Mastered (M)

Recognizes when a peer robot strays off-grid, locates the misplaced arrow card independently, and flips/replaces it.

Needs More (NM)

Confuses Left and Right relative to robot perspective; requires physical turn-mat or simplified 2x2 grid re-presentation.

Lower Elementary (Ages 6–9) Focus: Pattern Condensation, Base-2 Place Value & Grid Encoding

Introduced (I)

Understands doubled card values (1, 2, 4, 8, 16). Flips cards ON/OFF to construct target numbers up to 31.

Practiced (P)

Encodes 5-bit binary initials to string bracelets. Walks the outdoor sorting network accurately with numeric cards.

Mastered (M)

Encodes and decodes secret messages for peers using 5-bit keys. Demonstrates ScratchJr block sequencing to younger classmates.

Needs More (NM)

Mixes up place value positions (e.g. 1s place vs 16s place) or skips comparison nodes in sorting; needs 1-on-1 scaffolding.

Upper Elementary (Ages 9–12) Focus: Algorithmic Efficiency, Cryptography & Applied Scratch Logic

Introduced (I)

Participates in Parity Magic and Caesar Cipher presentations. Understands how parity bits detect transmission errors.

Practiced (P)

Constructs functional Scratch projects (Plant Tracker / Eco-Sorter) using variables, loops, and conditional statements.

Mastered (M)

Translates Scratch block logic into text-based syntax. Facilitates outdoor sorting network challenges for Primary students.

Needs More (NM)

Struggles with nested logic (If/Else) or identifying parity bit errors; benefits from flowcharting or guided bug isolation.

Observing Built-in Control of Error

Every CS Unplugged shelf work incorporates a physical or logical Control of Error. Guides assess mastery by observing whether the child engages the control independently before asking for guidance:

Grid & Physical Works

The "Robot" child physically landing on an obstacle or target serves as immediate spatial feedback.

Data & Binary Works

Control cards with visual dot sums, parity grid odd/even parity checks, or decoded letter keys.

Network Works

The final exit line standing in ascending numerical order provides visual proof of execution accuracy.
