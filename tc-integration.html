1 How to Add CS Unplugged to Transparent Classroom

Transparent Classroom allows you to define custom Subjects, Sub-Categories, and Lessons that reflect Montessori scope and sequences. Follow these steps to set up the CS Unplugged curriculum so guides can track progress, record observations, and generate parent reports.

Step 1: Admin Setup

Navigate to Admin > Lessons. Select your target level (e.g., Lower Elementary or Upper Elementary).

Step 2: Create Subject

Add a new Subject titled "Computer Science" or "Cosmic Education: CS Unplugged".

Step 3: Add Sub-Categories

Create three core sub-categories: Algorithms, Data Representation, and Information Theory (plus optional Applied Coding).

Step 4: Input Lessons

Enter individual shelf activities with descriptions, materials, control of error, and tracking stages (Presented, Practicing, Mastered).

3 Transparent Classroom Copy & Paste Lesson Entries

Use these pre-formatted fields when adding each lesson under Admin > Lessons > New Lesson in Transparent Classroom.

Lesson Entry 1: Kidbots Path Execution Sub-Category: 1. Algorithms & Procedures

Lesson Title:

Kidbots: Sequence & Debugging

Description / Direct Aim:

To write and execute a precise series of directional instructions (Forward, Left, Right) to navigate a floor grid. Teaches literal computer execution and debugging errors.

Prerequisites:

Spatial left/right orientation, 3x3 grid movement.

Materials Required:

5x5 Floor Grid (tape/mat), Directional Arrow Cards (Forward, Turn Left, Turn Right), Target Object (e.g., Golden Bead), Obstacle Cards.

Control of Error:

The "Robot" lands off-target or collides with an obstacle card when executing the code literally.

Assessment Stages:

1. Presented (Watches demo)
2. Practicing (Writes simple 3-step path)
3. Mastered (Programs around obstacles & fixes bugs)

Lesson Entry 2: Binary Cards & Base-2 Systems Sub-Category: 2. Data Representation

Lesson Title:

Binary Numbers: Base-2 Place Value

Description / Direct Aim:

To construct numbers using binary cards (1, 2, 4, 8, 16) by toggling cards ON (visible dots) or OFF (blank). Connects Base-10 decimal system to Base-2 digital logic.

Prerequisites:

Understanding of addition, Base-10 Decimal System (Stamp Game / Golden Beads).

Materials Required:

Set of 5 Binary Cards (1, 2, 4, 8, 16 dots), Binary Command Cards, Paper/Pencil for notation.

Control of Error:

Sum of visible dots on front of active cards equals target number printed on back of challenge card.

Assessment Stages:

1. Presented (Flips cards to show 1-15)
2. Practicing (Encodes given numbers)
3. Mastered (Encodes secret initial messages in binary)

Lesson Entry 3: Outdoor Sorting Networks Sub-Category: 3. Information Theory

Lesson Title:

Sorting Networks: Parallel Processing

Description / Direct Aim:

To physically move through a chalk network, comparing values at nodes with peers. Teaches algorithmic efficiency, parallel processing, and comparative sorting.

Prerequisites:

Number comparison (Greater than / Less than concept).

Materials Required:

Chalk Network on pavement (6 lanes), Number Cards 1-100, Stopwatches.

Control of Error:

Upon reaching the exit nodes, all participants hold up cards and are automatically lined up in ascending order.

Assessment Stages:

1. Presented (Participates in walk-through)
2. Practicing (Executes comparison rule with verbal greeting)
3. Mastered (Facilitates team run / explains parallel sorting)

Lesson Entry 4: Binary Bracelets & Encoding Sub-Category: 2. Data Representation

Lesson Title:

Binary Encoding: Craft & Cryptography

Description / Direct Aim:

To encode letters of the alphabet into 5-bit binary sequences using two bead colors (0 and 1) plus spacer beads. Demonstrates how computers store text in memory.

Prerequisites:

Binary Cards completion, fine motor stringing ability.

Materials Required:

2 bead colors (OFF/ON), spacer beads, elastic cord/pipe cleaners, 5-Bit Binary Alphabet Key.

Control of Error:

Peer decodes the bracelet/keychain back into letters using the Binary Key.

Assessment Stages:

1. Presented (Codes initial letter)
2. Practicing (Codes full name or word)
3. Mastered (Decodes peer work independently)

[Child's Name] practiced comparing numbers, following logic paths, and communicating effectively at each node."
