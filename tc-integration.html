Transparent Classroom Curriculum Integration

Step-by-step instructions for establishing the CS Unplugged curriculum structure, shelf activities, and 3-point progression tracking inside Transparent Classroom.

1 How to Add CS Unplugged to Transparent Classroom

Transparent Classroom allows guides to establish custom Subjects, Sub-Categories, and Shelf Lessons that reflect our 24-week Montessori CS Unplugged sequence. Follow these steps to set up the updated curriculum so guides can seamlessly track progress, document observations, and share photo updates with parents.

Step 1: Admin Setup

Navigate to Admin > Lessons. Select your level (Primary / 3-6 or Elementary / 6-12).

Step 2: Create Subject

Add a new Subject titled "Cosmic Education: CS Unplugged" or "Computer Science".

Step 3: Add Sub-Categories

Create four sub-categories: 1. Algorithms, 2. Data Representation, 3. Information Theory, and 4. Applied Capstone.

Step 4: Input Lessons

Enter individual shelf activities with descriptions, materials, control of error, and tracking stages (Presented, Practicing, Mastered).

Lesson Title:

1.1 The Great Story & Jam Sandwich Robot

Description / Direct Aim:

To write literal, step-by-step instructions for an actor "Robot" to assemble a sandwich. Demonstrates literal execution, ambiguity in code, and systematic debugging.

Prerequisites:

Everyday task sequencing, verbal or written communication skills.

Materials Required:

Sliced bread, jam/seed butter jar, butter knife, paper plates, wet wipes, index cards.

Control of Error:

The "Robot" actor literally follows instructions (e.g., placing unopened jar on bread if "open jar" step is missing).

Assessment Stages:

1. Presented: Watches live demonstration
2. Practicing: Writes 5-step sandwich algorithm
3. Mastered: Identifies missing steps and debugs code for 100% execution success

Lesson Title:

1.2 Kidbots Part 1: Floor Grid & Arrows

Description / Direct Aim:

To construct and execute directional arrow card sequences (Forward, Turn Left, Turn Right) guiding a peer "Bot" across a floor grid to a target object.

Prerequisites:

Spatial orientation (left/right awareness), basic grid movement.

Materials Required:

5x5 Floor Grid (tape/chalk), Directional Arrow Cards (Forward, Left, Right), target object.

Control of Error:

The "Robot" lands off-grid or misses the target when executing arrow cards literally.

Assessment Stages:

1. Presented: Watches demo lesson
2. Practicing: Programs 3-5 step path without obstacles
3. Mastered: Writes multi-step directional path independently

Lesson Title:

1.3 Kidbots Part 2: Obstacles & Debugging

Description / Direct Aim:

To navigate around floor grid obstacles, systematically trace execution steps, and identify and correct bugs when the "Bot" hits a barrier.

Prerequisites:

Completion of Kidbots Part 1.

Materials Required:

5x5 Floor Grid, Arrow Cards, Obstacle Cones/Cards, Bug cards.

Control of Error:

Collision with an obstacle card or stepping outside grid boundaries.

Assessment Stages:

1. Presented: Traces bug in sample code
2. Practicing: Navigates around 2 obstacles
3. Mastered: Debugs complex paths with 3+ obstacles independently

Lesson Title:

1.4 Rescue Mission: Loops & Subroutines

Description / Direct Aim:

To optimize long arrow sequences using "Repeat [N] Times" loop cards and reusable subroutine function blocks to reach a rescue target efficiently.

Prerequisites:

Kidbots Part 2, counting and pattern identification.

Materials Required:

Floor grid, Arrow cards, Loop cards (Repeat 2x, 3x, 4x), Function subroutine cards.

Control of Error:

Execution count fails to reach target cell or overshoots grid bounds.

Assessment Stages:

1. Presented: Learns loop card notation
2. Practicing: Shortens 6-card code using 1 loop
3. Mastered: Constructs multi-loop subroutines independently

Lesson Title:

1.5 Conditional Logic & Decision Paths

Description / Direct Aim:

To program decision paths using IF/THEN/ELSE conditional cards based on grid tile colors or obstacles encountered during traversal.

Prerequisites:

Basic sequencing and loops.

Materials Required:

Color-coded grid tiles, IF/THEN logic cards, direction tokens.

Control of Error:

Robot reaches incorrect end node when tile condition color changes.

Assessment Stages:

1. Presented: Observes IF red THEN turn left
2. Practicing: Executes 2-way conditional path
3. Mastered: Programs branching decision paths independently

Lesson Title:

2.1 Binary Numbers: Dots, Switches & Base-2

Description / Direct Aim:

To construct numbers using binary dot cards (1, 2, 4, 8, 16) and explore Base-2 exponential place values. Connects Base-10 math to digital bit switches.

Prerequisites:

Base-10 Decimal System (Stamp Game / Golden Beads).

Materials Required:

Set of 5 Binary Dot Cards (1, 2, 4, 8, 16 dots), ON/OFF switch mats.

Control of Error:

Sum of visible card dots equals target decimal number.

Assessment Stages:

1. Presented: Flips cards to show numbers 1-15
2. Practicing: Converts numbers up to 31
3. Mastered: Mentally converts binary-to-decimal and decimal-to-binary

Lesson Title:

2.2 Binary Alphabet & Bead Bracelets

Description / Direct Aim:

To translate text letters into 5-bit binary sequences using two bead colors (OFF=0, ON=1) to construct personalized binary name bracelets.

Prerequisites:

Binary numbers 2.1, fine motor stringing skills.

Materials Required:

5-Bit Alphabet Lookup Key, two bead colors (OFF=0, ON=1), string/pipe cleaner.

Control of Error:

Peer successfully decodes bead bracelet back into correct text letters using lookup key.

Assessment Stages:

1. Presented: Encodes initial letter into binary beads
2. Practicing: Strings 3-letter word bracelet
3. Mastered: Encodes and decodes full name independently

Lesson Title:

2.3 Image Representation (Pixel Art & Bitmaps)

Description / Direct Aim:

To fill in grid squares based on binary data strings (0=white, 1=black) to reveal hidden bitmap pixel images and explore how monitors display graphics.

Prerequisites:

Grid coordinate tracking, basic binary concept.

Materials Required:

8x8 or 10x10 grid sheets, black markers, binary pixel data cards.

Control of Error:

Filled grid reveals recognizable pixel image target (e.g., heart, house, star).

Assessment Stages:

1. Presented: Fills 5x5 pixel grid with guide
2. Practicing: Decodes 8x8 bitmap string
3. Mastered: Encodes custom picture into binary code string

Lesson Title:

2.4 Data Compression: Run-Length Encoding

Description / Direct Aim:

To compress bitmap pixel rows using Run-Length Encoding (RLE) count numbers (e.g., "3W, 2B, 3W") to reduce file size without losing information.

Prerequisites:

Image Representation 2.3.

Materials Required:

RLE challenge sheets, grid paper, compression calculation worksheet.

Control of Error:

Reconstructed grid matches target image exactly; total code length is shorter than uncompressed bit count.

Assessment Stages:

1. Presented: Observes line encoding demo
2. Practicing: Compresses 8x8 image using RLE
3. Mastered: Calculates compression ratios and decompresses complex images

Lesson Title:

2.5 Text & Pattern Compression

Description / Direct Aim:

To compress song lyrics and nursery rhymes by replacing repeating phrases with pointer symbols and dictionary lookup keys (LZW compression).

Prerequisites:

Reading fluency, pattern recognition.

Materials Required:

Song text sheets, dictionary box templates, colored highlighters.

Control of Error:

Substituting dictionary entries back into pointer symbols restores original text completely.

Assessment Stages:

1. Presented: Identifies repeated refrain in text
2. Practicing: Compresses 4-line poem with dictionary box
3. Mastered: Maximizes compression ratio on complex passages

Lesson Title:

3.1 Parity Magic: Error Detection Matrix

Description / Direct Aim:

To construct a grid of two-sided cards and add parity row/column bits (even count) to instantly detect when a card bit has been flipped.

Prerequisites:

Even and odd number recognition, grid coordinate tracking.

Materials Required:

36 two-sided black/white cards, grid work mat, parity challenge guide.

Control of Error:

The flipped card is always located at the intersection of the odd row and odd column.

Assessment Stages:

1. Presented: Observes teacher parity magic trick
2. Practicing: Sets up 4x4 grid parity bits with guide
3. Mastered: Performs trick independently and explains error detection logic

Lesson Title:

3.2 Parity Magic: Checksums & Reliability

Description / Direct Aim:

To calculate checksum digits for data packets and explore how networks detect corrupted data during digital transmission.

Prerequisites:

Parity Magic 3.1, multi-digit addition.

Materials Required:

Data packet cards, checksum calculation worksheets, transmission envelopes.

Control of Error:

Summed row/column check digits mismatch data payload when corrupted bit is inserted.

Assessment Stages:

1. Presented: Calculates 1D packet checksums
2. Practicing: Verifies data packet integrity in network simulation
3. Mastered: Explores 2D checksums and self-correcting Hamming codes

Lesson Title:

3.3 Search Algorithms: Linear vs. Binary Split

Description / Direct Aim:

To find a target value among ordered cards/cups by comparing sequential checking against splitting remaining search sets in half (Binary search).

Prerequisites:

Number ordering (1-30), greater than / less than comparison skills.

Materials Required:

30 ordered number cards or cups, search target token, stopwatch/timer, step logs.

Control of Error:

Binary search always isolates target item within a maximum of 5 comparison steps for 30 items.

Assessment Stages:

1. Presented: Watches middle-split demo
2. Practicing: Executes binary search on 15 cups
3. Mastered: Logs & explains logarithmic efficiency on large data sets

Lesson Title:

3.4 20 Questions & Decision Trees

Description / Direct Aim:

To construct binary decision trees that classify objects or animals using optimal yes/no questions to minimize search depth and entropy.

Prerequisites:

Taxonomic classification (Botany/Zoology charts), binary logic.

Materials Required:

Animal/plant cards, binary decision tree chart boards, note slips.

Control of Error:

Every leaf node leads to a single unique target without classification overlap.

Assessment Stages:

1. Presented: Follows 3-level branching tree
2. Practicing: Builds 8-item decision tree
3. Mastered: Optimizes question nodes for balanced tree efficiency

Lesson Title:

3.5 Outdoor Sorting Networks

Description / Direct Aim:

To physically navigate a chalk pavement network, comparing pair values at grid nodes to process parallel sorting algorithms.

Prerequisites:

Number ordering/comparison, gross motor spatial awareness.

Materials Required:

Chalk pavement network lines, numbered cards (1-6) or bead cards.

Control of Error:

All children exit the network arranged in perfect numerical order.

Assessment Stages:

1. Presented: Walks network with guide
2. Practicing: Navigates 6-person network correctly
3. Mastered: Explains parallel processing nodes and coaches peers

Lesson Title:

3.6 Cryptography & Caesar Cipher Modulo Math

Description / Direct Aim:

To encrypt and decrypt secret messages using rotating Caesar cipher wheels and modulo 26 clock arithmetic to explore cybersecurity and private communication.

Prerequisites:

Modulo/remainder math concept, reading fluency.

Materials Required:

Paper Caesar cipher wheels, brass fasteners, message key cards, cipher challenge sheets.

Control of Error:

Decoded text produces a meaningful English sentence using the designated key shift.

Assessment Stages:

1. Presented: Operates cipher wheel with teacher guidance
2. Practicing: Encrypts 3-word secret message with key shift +3
3. Mastered: Decodes encrypted message and explains modulo 26 wrapping logic

Lesson Title:

4.1 Capstone Planning & Storyboarding

Description / Direct Aim:

To design an interactive Scratch project flowchart and storyboard layout, mapping out sprites, events, and algorithms prior to digital implementation.

Prerequisites:

Completion of unplugged trimesters (Algorithms, Data, Info Theory).

Materials Required:

Storyboard planning sheets, colored markers, sprite template cards, flowchart symbol key.

Control of Error:

Flowchart logic connects start event to clear end/loop states without unhandled orphan actions.

Assessment Stages:

1. Presented: Reviews sample project storyboard
2. Practicing: Sketches 3-scene project sequence with sprite triggers
3. Mastered: Complete pseudocode and interactive flowchart independently prepared

Lesson Title:

4.2 Digital Interface Setup (Scratch / ScratchJr)

Description / Direct Aim:

To set up Scratch stage environments, custom sprites, backdrops, and coordinate movement (X/Y grid) translating unplugged spatial grid logic to screen.

Prerequisites:

4.1 Capstone Planning, basic computer navigation.

Materials Required:

Tablets or laptops with Scratch / ScratchJr, printed coordinate grid reference cards.

Control of Error:

Sprites align precisely on visual X/Y stage coordinates as designed in storyboard.

Assessment Stages:

1. Presented: Explores Scratch workspace layout and sprite paint editor
2. Practicing: Imports custom backdrop and positions 2 sprites on X/Y grid
3. Mastered: Configures complete visual interface ready for script blocks

Lesson Title:

4.3 Digital Logic: Variables & Conditionals

Description / Direct Aim:

To construct digital block scripts incorporating variables (score, timer) and conditional sensing blocks (IF touching color / sprite THEN perform action).

Prerequisites:

4.2 Digital Interface Setup, Unplugged Conditionals 1.5.

Materials Required:

Computers/tablets, Scratch block reference sheets, testing checklists.

Control of Error:

Scratch variable updates accurately when conditional collision occurs during play test.

Assessment Stages:

1. Presented: Watches live build of IF/THEN score counter
2. Practicing: Adds variable score increment to sprite interaction
3. Mastered: Builds complex multi-conditional script loop with game-over state

Lesson Title:

4.4 Peer Testing & CS Living Museum Showcase

Description / Direct Aim:

To conduct peer user testing, document and fix edge-case software bugs, and present interactive projects during a community CS Living Museum showcase.

Prerequisites:

4.3 Digital Logic.

Materials Required:

Finished Scratch capstone projects, peer feedback rubric forms, showcase display stands/mats.

Control of Error:

Peer play-tester verifies project executes without crash or broken loop logic.

Assessment Stages:

1. Presented: Conducts structured peer feedback session
2. Practicing: Identifies and debugs 2 peer-reported code glitches
3. Mastered: Presents finished interactive project to school community with confidence
